Examples
========

Complete, runnable tutorials. Notebooks are committed without outputs: read one here for the steps and
code, and run it on a GPU machine with the repository checked out to see the tables and 3D views.
All four tutorials include optional Colab setup for A100 High RAM. Python API input preparation
and antibody generation/refinement can run on Colab. Enzyme and PPI tutorials support input
inspection only and mark where to stop. Oracle refolding is unsupported on Colab.
