RFD4-Proteína documentation
===========================

**RFD4-Proteína** is a flow-matching foundation model for designing proteins,
RNA, DNA, and small-molecule complexes under rich structural and functional
conditioning.

Start with the :doc:`quickstart tutorial <tutorial/quickstart>` to install the
model and generate a first design. The user guides then cover input
preparation, design tasks, reward-guided search, evaluation, and development.
