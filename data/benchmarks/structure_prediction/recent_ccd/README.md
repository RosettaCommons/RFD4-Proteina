# Recent CCD validation panel

These 43 annotated CIF inputs were selected using recent PDB and CCD data. None
of them were present in the OMol or PDB training sets. All examples represented in
the PDB were deposited in 2025 or later.

Each task co-generates an unconditioned ligand conformation and a 100-residue
protein. The ligand coordinates in the input provide reference stereochemistry
but are not coordinate-conditioned.

The panel assesses:

- adherence to assigned chiral centers;
- adherence to assigned E/Z bond stereochemistry; and
- ligand geometry and physical plausibility with PoseBusters.
