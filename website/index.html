Design quality

How often a model produces a design that survives an AlphaFold3 refold, scored for every model through one metric code path. MCSA: enzyme active-site scaffolding, motif RMSD native↔refold. DISCO: de-novo ligand binders, design↔refold self-consistency. PPI: de-novo protein binders, refolded interface pTM / iPAE plus binder RMSD to the designed pose. Clustered counts distinct passing folds (Foldseek, TM 0.5), so a model cannot win by emitting the same success repeatedly.

Units

per GPU-hour divides by sampling cost measured on an older checkpoint, which has not been re-measured.
