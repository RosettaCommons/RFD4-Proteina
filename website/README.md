Run `python -m http.server 4187 --bind 127.0.0.1 --directory website` from the repository root.
Open <http://127.0.0.1:4187/> or <http://127.0.0.1:4187/leaderboard.html>.

Pages: `index.html` and `leaderboard.html`. Results: `benchmarks/data.json`.
Benchmark logic: `benchmarks/*.mjs`. Artwork and structure viewers: `assets/`.
